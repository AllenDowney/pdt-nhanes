# Working in pdt-nhanes

National Health and Nutrition Examination Survey (NHANES) metadata built to the PublicDataToolkit standard (`../PublicDataToolkit/STANDARD.md`). To build or improve this repo, follow `../PublicDataToolkit/instructions/`. To search the metadata, read `agent/index.md` first.

- `metadata/releases/<cycle>/<table>/`, `metadata/derived/` and `build/report.md` are generated by `build/build_records.py`, which builds every variable of the files listed in `build/slice.yaml`. Don't edit them; change the build or `build/slice.yaml`.
- `agent/`, `docs/` and `export/` are generated by `make views`. Don't edit them.
- `dataset.yaml`, `sources.yaml`, `EXTENSIONS.md`, `build/slice.yaml` and `metadata/corrections.jsonl` are edited by hand.
- `data/` is gitignored and never committed.
- Run builds under the memory cap: `systemd-run --user --scope -p MemoryMax=6G -p MemorySwapMax=0 --quiet make build`.
- Read XPT files with pyreadstat, not pandas: pandas' XPORT reader turns an exact zero into 5.4e-79.
- Run `make build`, `make views`, then `make check`. Read `build/report.md` after every build.
- Terms questions go to a person; don't decide them.
