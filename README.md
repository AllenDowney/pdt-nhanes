# pdt-nhanes

Metadata for the [National Health and Nutrition Examination Survey (NHANES)](https://wwwn.cdc.gov/nchs/nhanes/), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** three cycles (2015-2016, 2017-March 2020 pre-pandemic, August 2021-August 2023), each with four files taken whole and linked on SEQN: demographics, the PHQ-9 depression screener, body measures and glycohemoglobin. The terms are decided (everything ships), but nothing is published yet.

## What the dataset is

NCHS's survey of the health and nutrition of the US civilian noninstitutionalized population, combining interviews with physical examinations and laboratory tests at mobile examination centers. Released in two-year cycles of linked files.

## Terms of use

The terms are at https://www.cdc.gov/nchs/policy/data-user-agreement.html. Allen Downey reviewed the terms on 2026-11-20: the metadata, the documentation and the common-format data ship, with this notice:

> Source: National Center for Health Statistics, National Health and Nutrition Examination Survey, public-use data files. Use is subject to the NCHS Data User Agreement (https://www.cdc.gov/nchs/policy/data-user-agreement.html): the data may be used only for statistical reporting and analysis, and users must not attempt to identify any person or link the data to identifiable data.

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum: NCHS posts each file's data (`.xpt`, SAS transport) and its codebook (`.htm`) at wwwn.cdc.gov without registration. `make download ARGS=--accept-terms` fetches them; the NCHS agreement page has to be saved from a browser.

## How to use the metadata

- `metadata/releases/<release>/variables.jsonl`: one record per variable, with where each fact came from.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

Centers for Disease Control and Prevention (CDC). National Center for Health Statistics (NCHS). National Health and Nutrition Examination Survey Data. Hyattsville, MD: U.S. Department of Health and Human Services, Centers for Disease Control and Prevention.

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make views
make check
```

The metadata tools (`make views`, `make check`) need only the toolkit's base install
(`pip install -e ../PublicDataToolkit`). Building or reading the data files (`make data`,
`scripts/extract.py`, and the data checks in `make check`) also needs pandas, numpy and
pyarrow: `pip install -e "../PublicDataToolkit[data]"`. Without them, `make check` skips
the data checks and says why.
